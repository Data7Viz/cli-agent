## JSON не сталкивался с этим зверем
Ключ <-> Значение

- **Ключ** это всегда название параметра в кавычках.
- **Значение** это то, что в этом параметре записано. 
- **Пример** "model": "qwen2.5-coder:7b" 

### JSON Ключ верхнего уровня

- **"model"** указывает какую именно модель запустить.
- **"messages"** это вся история диалога которую агент передаёт серверу. [....] внутри этих скобок лежит диалог (массив).
- **"stream"** управляет тем как возвращать ответ. false / true 

### JSON Второй слой

- **"role"** указывает кто говорит. У этого ключа три основных значения.
- **"system"** системная инструкция (правило поведения агента).
- **"user"** промт\вопрос от пользователя или данные от инструментов.
- **"assistant"** ответ самой нейросети.
- **"content"** текст сообщения (промт или ответ модели). 

```
{
    "model": "qwen2.5-coder:7b",
    "stream": false,
    "messages": [
        {
            "role": "system",
            "content": "Ты автономный агент, твоя цель писать чистый закомментированный код"
        },
        {
            "role": "user",
            "content": "Привет твоя главная цель?"
        }
    ]
}, 

``` 

Запятая по идее конец инструкции.
