# JSON Network

## Содержимое конфигурации
- **network.json** Сеть ip адес, порт, эндпоинт, API.
- **prompt.json** Управление автоматизацией.
- **schema.json** Подсказки, автодополнение, проверяет синтаксис.

## schema.json
Без автодополнения и подсказок вникать в JSON сложно. Содержимое файла сгенерировал браузерный ИИ. Практиковаться буду утилитой curl. ИИ агент мы понимаем, что автоматизация. Без базы JSON Агента не запрограммировать.
